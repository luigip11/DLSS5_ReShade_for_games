# Versione del gioco

Dopo l’analisi, la pagina Gioco mostra **Versione dichiarata nell’EXE**, con i campi Versione prodotto e Versione file letti dalle risorse dell’eseguibile senza avviarlo. I valori sono inclusi anche nel report JSON esportato.

Un campo assente viene mostrato come **Non disponibile**. Nei giochi meno recenti questi dati possono essere mancanti o rimanere invariati dopo una patch: non costituiscono una certificazione della versione installata. Il nome del file non viene usato per dedurre una patch.

Il riconoscimento di un eseguibile tramite SHA-256 e le verifiche di compatibilità dei componenti rimangono separati. Il catalogo attuale non associa all’EXE UG2 collaudato una versione commerciale certa (1.0, 1.1 o 1.2).

I report precedenti, privi del campo Version, restano leggibili. Per ottenere il nuovo dato occorre analizzare nuovamente il gioco.
